02 / How access works

Request → review → Access policy → login.

Nothing is automatic. Cloudflare only lets through emails that an admin has placed on the policy.

1

Request media access

Submit name, email, and Private Media (or Other for a general question). The form emails the admin. Infrastructure access is not available here.

2

Manual review

An admin decides. If approved, your email is added to the Cloudflare Access application that protects the media host.

3

Edge identity check

You visit jellyfin.nebulaservices.live. Cloudflare shows its login first. You prove you control the approved email (e.g. one-time code).

4

Use the library

After Access succeeds, Jellyfin loads. On mobile, install Cloudflare One (WARP), stay connected, and use the official Jellyfin app.

04 / What you will not get

Clear boundaries.

Approved media users get access to the private library under the rules on the Legal page. They do not receive server control, Cloudflare dashboard access, the ability to invite others, or any infrastructure role.

Those surfaces stay with the operators. If you only need the library, use the request form. Everything else is out of scope for public requests.
