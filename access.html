Access request

Request private
media access.

This form is only for the private media library. Infrastructure and admin systems stay private and are not available through this form. Every submission is emailed to the admin for manual review.

This email will be added to Cloudflare Access (if approved) and will receive your login / auth codes.

What happens next

  1. You submit the form Your details are emailed directly to milnerg-admin@nebulaservices.live.
  2. Manual review Requests are reviewed by an admin. Approval is discretionary — there is no automatic grant.
  3. Email added to Cloudflare Access If approved, your email is added to the Cloudflare Access policy for the media host.
  4. You sign in Visit jellyfin.nebulaservices.live, authenticate with that email, and complete the Cloudflare Access login.
Media access only. Infrastructure, admin panels, and internal systems are not offered through this form and remain private to the operators.

Prefer email directly?
milnerg-admin@nebulaservices.live

What you get with media access

Approved users can reach the private Jellyfin library at jellyfin.nebulaservices.live after passing Cloudflare Access. Browser use works after a one-time (or periodic) identity check. Mobile use requires the official Jellyfin app plus the Cloudflare One (WARP) agent with an active session.

You do not get admin rights, server control, infrastructure access, or the ability to invite others. Access is personal to the approved email and can be revoked at any time.
