02 / How Cloudflare Access works

Identity at the edge
before the app.

Cloudflare Access sits in front of jellyfin.nebulaservices.live. Nobody reaches the Jellyfin login page until Cloudflare has checked that their email is on the allow list.

The flow in plain language

  1. You request access Submit the form on the Request Access page. An admin reviews it. Infrastructure and admin systems are never offered through that form.
  2. Your email is added to the policy If approved, the admin adds your email to the Cloudflare Access application policy for the media host. Only emails on that list can pass the gate.
  3. You visit the URL Open jellyfin.nebulaservices.live. Cloudflare intercepts the request and shows its Access login screen — not Jellyfin yet.
  4. You prove identity Enter the approved email. Cloudflare sends a one-time code (or uses another configured method). After you complete that step, Cloudflare issues a short-lived session and lets the request through to Jellyfin.
  5. Jellyfin loads Only then do you see the Jellyfin interface. You may still need a Jellyfin account inside the app if one was created for you; the Cloudflare step is the outer lock.
◈

Browser

Desktop and mobile browsers work after Cloudflare Access succeeds. The session is stored as a cookie for a limited time; when it expires you authenticate again.

📱

Mobile apps

Official Jellyfin apps cannot complete Cloudflare’s browser login by themselves. You install Cloudflare One (WARP), sign in with the same approved identity, and keep the agent connected while using the app.

03 / Mobile setup

Cloudflare One + Jellyfin

Native Jellyfin clients talk to the server over the network. Because the host is protected by Access, traffic from the app is blocked unless the device is already authenticated via Cloudflare’s agent.

  • Install Cloudflare One (also called WARP) from your platform’s store or Cloudflare’s site.
  • Sign in with the same email that was approved for Access.
  • Connect the agent so device traffic is allowed through the Zero Trust path.
  • Open the official Jellyfin app and point it at https://jellyfin.nebulaservices.live.
  • Keep WARP connected while streaming. If the agent disconnects, the app will lose access until you reconnect.

Exact menu names can vary by Cloudflare One version and OS, but the idea is the same: the agent proves device identity so Access allows the app’s traffic.
